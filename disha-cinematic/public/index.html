const axios = require('axios');

async function createSovereignOrder(amount, token) {
  const res = await axios.post(
    'https://your-domain.com/api/merchant/payments',
    { amount, customer_name: 'Ramesh Stores' },
    { headers: { Authorization: `Bearer ${token}` } }
  );
  return res.data;
}

A few things worth knowing.

Because choosing your payment software is a business decision, not just a design preference.

What exactly am I buying?+

A perpetual license for the agreed DISHA software version, plus installation and handover services in your quotation. The intellectual property stays with DISHA unless separately agreed.

Do I pay DISHA every month?+

No recurring DISHA software subscription under this model. Your own hosting, network or banking charges, taxes, and optional services remain separate.

How is my price calculated?+

Four months of verified monthly net savings: genuinely removable costs, less new ongoing expenses introduced by your deployment.

Does DISHA guarantee a payment is safe?+

No. The platform includes transaction and evidence controls to improve visibility and reduce specific operational risks, not a guarantee that fraud cannot occur.

Existing merchants can log in now. New merchant access requires authorized provisioning; use the estimate to understand the commercial model while onboarding is arranged.
