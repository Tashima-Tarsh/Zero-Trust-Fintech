DISHA Android → Chrome SMS Transport Experiment

Test-only. No payment is started. No SMS is uploaded, saved, or transmitted to DISHA.

Question: can Chrome receive a bank-like debit SMS through WebOTP?

This experiment separately injects a synthetic bank alert and an origin-bound OTP via Android Emulator ADB. A WebOTP result is NOT a bank debit or a general SMS reader.

Experiment procedure
  1. Open this page through local Chrome on the emulator using the supplied ADB script.
  2. Tick consent and press Start; keep the page open and note the displayed 6-digit code.
  3. Run run.ps1 -Mode Debit and observe whether Chrome returns a code.
  4. Restart the 90-second listener, run run.ps1 -Mode Otp -Code 123456, replacing 123456 with the displayed code. If the phone prompts, accept it.
  5. Compare the states. Bank-like SMS delivery to Android is distinct from Chrome getting the full bank SMS.

This does not test real banking SMS, message origin authenticity, root/debugger attestation, or customer production checkout.
