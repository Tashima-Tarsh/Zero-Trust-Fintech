DISHA UDEB — Production-Origin Research Console

Read-only experiments on the actual DISHA HTTPS origin. No payment, ledger, SMS access or evidence verification is performed by this page. Only explicit button clicks initiate browser APIs. Browser support does not establish Android debit acquisition.

A — Browser capability matrix

Identifies what the current browser exposes; not evidence of UPI support.

B — Claude H-C: Digital Credentials custom dispatch

Requests a non-payment experimental credential protocol with a fresh nonce. It may fail in Chrome before reaching Android Credential Manager. No Android provider exists in this repository.

C — WebOTP interface availability

Checks whether WebOTP is exposed. It does not read SMS and does not start an SMS retrieval operation.

D — PaymentRequest API availability

Checks API presence only. Personal UPI payment response and blank-MCC compatibility require separate authorized live tests.

E — Production DDEB verifier status

Read-only capability report. Server-side signed evidence contract is not a bank-debit verifier and this page does not create evidence.

F — Platform integration gates

ASTEOS system SMS/notification observation, native consent, AOSP signer and Chrome Binder transport require separate platform implementation. This console cannot activate those services on an unmodified Android phone.
